# Asset Register Backend Submission

This backend source is staged here for review and later integration into the shared FFIMS backend.

## Included
- backend source package
- `docs/` for API, database, and integration notes
- `tests/` for API smoke-check guidance
- `.env.example` for backend environment setup

## Important
Do not treat the standalone `.env.example` values as final shared-system secrets. Shared authentication and environment alignment should happen during integration.

## Key backend contribution
The backend includes the replacement-priority planning engine that powers executive dashboards and AI-assisted planning summaries.
