# Database Notes

## Main Collections Used by Module 2
- assets
- maintenancelogs
- assetdocuments
- users

## Important Asset Fields
- assetId
- name
- category
- location
- status
- purchaseDate
- purchaseCost
- currentValue
- usefulLife
- depreciationRate
- condition
- custodian

## Planning Data Inputs
The replacement-priority engine uses:
- purchase cost and current value
- useful life and purchase date
- status and condition
- maintenance history
- overdue maintenance dates
- active document coverage

## Why This Matters
This allows the module to move beyond basic listing and support budgeting, replacement planning, and management review.
